# Security Policy

Report security or privacy issues privately to **info@snacustoms.co.za**.

Security principles:
- no repository secrets;
- no server-side form processing in the current build;
- WhatsApp project brief is composed client-side and only sent after user confirmation;
- third-party video loads only after interaction;
- CSP restricts resources to the site and required media host;
- GitHub Actions use explicit least-privilege permissions.
