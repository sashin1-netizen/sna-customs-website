# Design System

## Brand language

Workshop black, aged paper, aluminium greys and restrained competition orange/red. The car provides most of the colour.

## Type roles

- Display: condensed system fallback stack
- Body: system sans-serif
- Technical labels: system monospace

## Motion

- UI feedback: ~200ms
- Scene/reveal: ~700ms
- Ticker: slow continuous movement; disabled for reduced-motion users

## Responsive rule

Mobile is a separate art-directed composition, not a shrunken desktop layout. Content stacks, labels reduce, crops change, and touch actions remain at least ~44px high.
