# Contributing

Use `feature/*`, `fix/*` or `chore/*` branches. Keep commits focused and use descriptive prefixes such as `feat:`, `fix:`, `perf:`, `a11y:`, `test:` and `docs:`.

Before opening a PR:
- run static QA;
- run Playwright checks;
- review mobile and desktop screenshots;
- verify no fabricated client proof was introduced;
- document performance/accessibility impact.
